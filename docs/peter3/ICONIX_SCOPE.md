# Alcance ICONIX

ICONIX corresponde al proceso de desarrollo del proyecto SAVP completo. Aporte Ingenieril SAVP implementa el servicio analítico y aporta contratos, modelos y pruebas; no afirma cumplimiento completo de ICONIX sin requisitos globales, modelo de dominio, casos de uso, análisis de robustez, secuencias y modelo de clases acordados por todo el proyecto.

**ICONIX robustness analysis** es una técnica de análisis de casos de uso. **Recommendation robustness** en Aporte Ingenieril SAVP evalúa la sensibilidad de recomendaciones experimentales. Son actividades distintas y sus resultados no se sustituyen.
