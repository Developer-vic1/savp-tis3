# Crosswalk carrera–ocupación

El crosswalk versionado contiene 15 relaciones para cinco ofertas académicas. Carrera y
ocupación son constructos distintos: las relaciones son `DOCUMENT_SUPPORTED_INFERENCE`, no
equivalencias ni garantías laborales. Los códigos ISCO-08 y O*NET-SOC fueron contrastados con
las taxonomías oficiales vigentes durante la auditoría.

Correcciones O*NET 31.0 relevantes:

| Ocupación | Código | Perfil RIASEC oficial usado |
|---|---|---|
| Software Developers | `15-1252.00` | `IC` |
| Computer Systems Analysts | `15-1211.00` | `IC` |
| Computer Network Architects | `15-1241.00` | `ICR` |
| Clinical and Counseling Psychologists | `19-3033.00` | `SIC` |
| Industrial-Organizational Psychologists | `19-3032.00` | `IEC` |
| School Psychologists | `19-3034.00` | `SIC` |
| Civil Engineers | `17-2051.00` | `RIC` |
| Environmental Engineers | `17-2081.00` | `IRC` |
| Environmental Scientists and Specialists | `19-2041.00` | `IRC` |

El código retirado `19-3031.00` no se usa. Las relaciones ISCO incluyen, entre otras, `2512`
(desarrollo de software), `2634` (psicología), `2142` (ingeniería civil) y `2143` (ingeniería
ambiental). Los perfiles RIASEC ocupacionales son referencias sobre intereses de ocupaciones;
no constituyen resultados psicométricos del estudiante.

Las pruebas validan los códigos, perfiles, fuentes y resolución de todas las referencias.
